# تعديلات برنامج مرحلتي

تم تعديل المشروع لإضافة نظام المرحلة وإدارة حسابات الطلبة.

## تسجيل الطالب
- اختيار الكلية.
- اختيار القسم التابع للكلية.
- اختيار المرحلة: الأولى، الثانية، الثالثة، الرابعة.
- اختيار الشعبة: A / B / C / D.
- تم إرسال المرحلة إلى الخادم وحفظها في قاعدة البيانات.

## حساب المسؤول
أضيفت واجهة «إدارة حسابات الطلبة» داخل لوحة المسؤول، وتسمح بـ:
- مشاهدة جميع حسابات الطلبة المسجلة.
- تعديل اسم الطالب والكلية والقسم والمرحلة والشعبة.
- تفعيل الحساب أو تعطيله.
- تغيير/إعادة تعيين رمز الطالب.
- حذف حساب الطالب مع حذف سجلات الحضور والإشعارات المرتبطة به.

## الخادم
تمت إضافة الحقول `stage` و `is_active` إلى جدول المستخدمين مع ترحيل تلقائي لقاعدة البيانات القديمة عند تشغيل الخادم.

## ملاحظة البناء
تم تعديل ملفات المصدر في Android وFastAPI. لم يتم إعادة بناء APK داخل بيئة العمل الحالية لأن Gradle حاول تنزيل توزيعة Gradle من الإنترنت، والبيئة الحالية لا تسمح بالاتصال الخارجي. افتح المشروع في Android Studio ثم نفّذ Build > Make Project أو Build APKs.


## التعديلات الجديدة
- حفظ جلسة تسجيل الدخول للطالب على الهاتف، واستعادتها تلقائياً عند فتح التطبيق.
- الجلسة محفوظة في الخادم لمدة 30 يوماً، وتبقى صالحة بعد إعادة تشغيل السيرفر.
- زر «خروج» يلغي الجلسة من الخادم ومن الهاتف.
- لوحة «الإعلانات» أصبحت تستهدف: الكلية + القسم + المرحلة.
- عند نشر الإعلان يتم إنشاء إشعار تلقائياً فقط للطلبة المطابقين للكلية والقسم والمرحلة.
- لوحة رفع الملفات أصبحت تستهدف: الكلية + القسم + المرحلة، مع خيار إرسال الملف لكل الشعب أو لشعبة محددة.
- الملفات والإعلانات أصبحت تُفلتر للطالب حسب بياناته الأكاديمية.
- عند تعطيل الطالب أو تغيير كلمة مروره يتم إلغاء جلساته المحفوظة.
- إشعارات النشر موجودة داخل تبويب «الإشعارات» ويتم تحديثها تلقائياً كل 30 ثانية أثناء استخدام التطبيق.

## تحديث حسابات التدريسيين وسجل النشاط
- أضيف تسجيل مستقل للتدريسي من شاشة الدخول، مع ربط الحساب باسم المادة ورمزها والكلية والقسم والمرحلة والشعبة.
- دور جديد `lecturer` بصلاحيات محصورة بالمادة المرتبطة بالحساب.
- لوحة التدريسي تعرض طلاب مادته وتسمح بتسجيل: حاضر / غائب / متأخر، ونشر إعلان موجّه لهم.
- أضيفت إدارة حسابات التدريسيين في لوحة المسؤول مع إمكانية طرد جلساتهم.
- أضيف زر **طرد** مستقل للطلاب، بدون تعطيل الحساب، يقوم بإنهاء جميع الجلسات الحالية.
- أضيف جدول `audit_logs` وسجل في لوحة المسؤول للأحداث: التسجيل، دخول، خروج، طرد، تعطيل، تفعيل، حذف، تغيير رمز، تحديث حضور وإعلان تدريسي.
- سجل الأحداث يحتفظ باسم المنفذ والمستخدم المستهدف والتفاصيل والتاريخ حتى إذا حُذف الحساب لاحقاً.
- أضيف `stage` للمقررات و `lecturer_course_id` للمستخدمين مع ترقية تلقائية لقواعد البيانات القديمة عند تشغيل الخادم.

> ملاحظة: حدث "الخروج" يسجل عند استخدام زر خروج داخل التطبيق. إغلاق التطبيق بالقوة لا يرسل طلب خروج إلى الخادم تلقائياً.
